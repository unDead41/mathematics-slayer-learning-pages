# Mathematics Slayer — learning portal preview

This repository contains the compiled website for GitHub Pages.

The landing, BM/BI account interface and Guest topic selection are available.
Real account services, the three full learning modules and game synchronization
are still being prepared. Account forms report unavailable rather than simulate
successful registration in this production build.

Only public website artifacts are stored here. Private source, backend migrations,
tests and configuration are maintained separately.
